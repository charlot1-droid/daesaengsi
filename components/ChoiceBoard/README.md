# ChoiceBoard

선택지는 화면 위쪽에 질문 판과 세 줄의 답 카드를 세로로 쌓아요. 세 카드는 **모두 같은 핑크빛 흰색 유리이고, 잉크색 번호 배지(1·2·3)로만** 구분해요.

- 특정 번호에 색을 주지 않아요. 1번이 더 로맨틱하거나 정답처럼 보이지 않게 하려는 거예요.
- 투표 중에는 질문 판 아래에 투표 인원만 실시간으로 올라가요. 답별 표 수는 숨겨요.
- 1·2·3이 0.1초 간격으로 차례로 나타나고, 셋 다 보인 뒤에 투표가 열려요.
- 결과(`data-phase="result"`): 이긴 답 카드만 장미색 테두리·배지·막대로 바뀌어요. '이야기가 고른 길'이라는 뜻이에요. 나머지는 글자만 흐려지고 카드는 불투명하게 남아요.
- 타이머는 10초 이하 `warn`, 5초 이하 `alert`, 0초 '마감'이에요. 화면 전체를 깜빡이지 않아요.
