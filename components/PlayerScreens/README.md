# PlayerScreens

관객 휴대폰 화면은 로그인 없이 입장 번호와 이름만으로 들어와, 번호가 붙은 세 버튼 중 하나를 누르는 모바일 UI예요.

- 흐름: 입장 → 기다리기 → 투표 → 투표 완료(마감 전 변경 가능) → 결과 → 다시 기다리기.
- 버튼 세 개는 무대와 똑같이 같은 핑크빛 흰색에 잉크 번호 배지예요. 누른 버튼만 장미색 테두리와 배지로 바뀌고, 나머지는 흐려져요.
- 상태는 색만이 아니라 글로도 알려요: '전송 중', '2번 선택 완료', '전송 실패, 다시 눌러 주세요'.
- 버튼 높이 88px, 질문 24px, 입력칸 글자 18px예요. 16px 미만 글자는 쓰지 않아요.
