# Prop

소품은 이야기 속 실제 물건(냅킨 쪽지, 메뉴판, 통장, 시간표)을 가까이서 보여 주는 장면이에요. 판에 글자만 띄우지 않고, **생성한 그림 위에 글자를 얹어요.**

- 그림은 ChatGPT로 **글씨 없는 빈 물건**을 투명 배경으로 생성해요(`pr-<물건>.png`). 한글은 AI 이미지에서 깨지기 쉬워서, 내용은 화면에서 글꼴로 얹어요. 대본을 고치면 글자도 바로 바뀌어요.
- 글씨 종류 `data-hand`: `pen`(볼펜 손글씨, 남색 잉크), `chalk`(분필, 메뉴판), `print`(인쇄체, 통장·시간표).
- 위치는 물건마다 `--x`, `--y`, `--w`, `--rot`(물건 기울기에 맞춤), `--fs`(글자 크기)로 맞춰요.
- 뒤 장면은 살짝 어둡게 가라앉히고, 소품이 아래에서 0.6초 동안 올라와요. 소품 크기는 720px 안팎, 화면 위쪽 가운데예요.
