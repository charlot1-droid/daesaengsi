# StageSplash

스테이지 표지는 새 스테이지가 시작될 때 그 장면의 일러스트 위쪽 가운데에 제목을 띄워요. **판 없이** 흰 제목과 어두운 블러 후광, 그림자만 써서 제목이 그림 위에 떠 보여요.

- 구성: `Stage n`, Wanted Sans Black 112px 제목, 한 줄 부제예요. 글자는 모두 흰색이에요.
- 후광: 제목 뒤를 타원으로 22px 흐리고, 짙은 로즈(#843A58)를 48%에서 0%로 옅게 깔아요. 가장자리는 투명하게 사라져서 상자 모서리가 보이지 않아요.
- 그림자: 벚꽃 배경에 어울리는 짙은 로즈(#682642)로 가까운 그림자(4px, 10px 흐림)와 넓은 그림자(12px, 44px 흐림)를 겹쳐서 밝은 벚꽃 위에서도 흰 글자가 또렷해요. 낮과 밤 장면 모두 같은 처리예요.
- 후광 자리에 인물 얼굴이 오지 않게, 장면 일러스트는 위 1/3을 하늘·벚꽃으로 비워 둬요.
- 0.6초 동안 위에서 내려오며 나타나요. 반짝이나 아이콘 장식은 붙이지 않아요.
