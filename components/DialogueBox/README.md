# DialogueBox

대사창은 **화면 위쪽**에 놓이는 흰색 유리 판(84% 흰색 + 뒤 그림 블러)이고, 왼쪽 위에 화자 이름 탭이 걸쳐 있어요. 강당 뒷줄에서는 앞사람 머리가 화면 아래를 가리기 때문에 일반 미연시와 달리 위에 둬요.

- 이름 탭: 남주는 잉크 채움, 여주는 잉크 테두리('김여주 나'), 나레이터는 탭 없이 한 단계 낮은 면(`panel-2`)을 써요.
- 대사는 고운돋움 50px로 1~2줄 써요(한 줄 20~28자). 이름 탭은 굵은 Wanted Sans라 대사와 확실히 구분돼요. 지문 ( )은 Wanted Sans로 작고 흐리게 써요. 한 줄 20~28자가 기준이고, 넘치면 대본을 나눠요.
- 한 줄 전체가 0.7초 안에 드러나요(`m-type`). 클릭하면 즉시 전체가 보여요.
- 여주와 나레이터 대사도 다른 대사와 똑같이 보여 줘요. 따로 표시하지 않고, 무대 모드를 켜면 화면에서 숨겨요.
- 스테이지 이름, 호감도, 참여 인원은 화면 **아래 모서리**의 작은 칩으로 내려요. 뒷줄에서 못 봐도 되는 정보예요.
