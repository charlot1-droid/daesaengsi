# 대생시 Design System

**대생시: 대학 생활 시뮬레이션**은 고3 초청채플 레크리에이션용 미연시 게임이에요. 장면은 무대 스크린에 나오고, 관객은 휴대폰으로 세 개의 답 중 하나를 골라 이야기를 움직여요. 이 문서는 무대 화면, 관객 휴대폰, AI 일러스트를 하나의 시스템으로 묶어요.

> 무대에서는 그림이, 휴대폰에서는 세 개의 답이 주인공이에요. 인터페이스는 그 둘을 방해하지 않게 조용히 있어요.

## 화면 세 가지

| 화면 | 누가 보나 | 기준 | 무엇이 주인공인가 |
| --- | --- | --- | --- |
| 무대 화면 | 강당 전체 (빔프로젝터) | 1920×1080, 16:9 | 일러스트. 읽을 것(대사·질문·선택지)은 화면 위쪽, 보조 정보는 아래 모서리 |
| 관객 휴대폰 | 관객 각자, 로그인 없이 | 360~430px 폭 | 세 개의 답 버튼 |
| 진행자 조작 | 진행자 노트북 | 무대 화면 + 단축키 | 클릭·스페이스로 진행, 1·2·3으로 직접 고르기, ←로 뒤로 |

## 원칙

1. **읽을 것은 위에 둬요.** 강당 뒷줄에서는 앞사람 머리가 화면 아래를 가려요. 그래서 대사창, 질문, 선택지, 공지는 모두 화면 위쪽에 두고, 스테이지 이름·호감도·인원 같은 보조 정보만 아래 모서리에 둬요. 일러스트도 인물 얼굴이 화면 가운데에 오게 그려요.
2. **그림이 색을 맡아요.** 인터페이스는 핑크빛 흰 유리 판(`panel`)과 코코아 브라운 잉크(`ink`, #523B37) 두 가지예요. 장미색(`rose`)은 감정(호감도)과 '이야기가 고른 길'(투표 1등)에만 써요.
3. **판은 한 가지예요.** 모든 판이 같은 `.ds-panel` 레시피를 써요: 핑크빛이 도는 흰 유리(86% #FFF9FC, 뒤 그림 18px 블러), 흰 빛 2px 테두리, 하나뿐인 모서리 `r-ui` 24px, 아래로 떨어지는 그림자. 그림의 색이 살짝 비쳐서 판이 장면에 섞여요.
4. **답은 번호로 불러요.** 세 답 카드는 같은 색이고 잉크색 번호 배지 1·2·3으로만 구분해요. 특정 번호에 색을 주면 그 답이 정답처럼 보여요. 진행자도 "2번!"이라고만 말하면 돼요.
5. **글꼴은 두 가지예요.** 대사만 **고운돋움**으로 써서 부드러운 로맨스 톤을 내고, 이름 탭(굵은 Wanted Sans)과 확실히 구분돼요. 획이 얇아서 50px 아래로 쓰지 않아요. 제목, 이름, 질문, 선택지, 숫자, UI는 모두 **Wanted Sans**(제목 900, 이름·질문 800, 선택지 600)예요. 꼭 읽어야 하는 정보는 36px 아래로 내리지 않아요.
6. **움직임은 연출 도구예요.** 판은 위에서 12px 내려오며 나타나고(0.25초), 선택지는 0.1초 간격으로 차례로 나타나고, 결과 막대는 0.75초 동안 차올라요. 배드 엔딩만 0.2초 흔들려요. 대사는 한 줄 전체가 0.7초 안에 드러나요. `prefers-reduced-motion`이면 모두 멈춰요.

## 말투

- 남주는 다정한 존댓말("~해요"), 친구는 반말, 나레이터는 예능 MC 톤이에요.
- **1인칭:** 플레이어가 곧 여주예요. 여주의 얼굴은 어디에도 그리지 않고, 대사창에는 '김여주 나'로만 표시해요.
- 화면 문구와 버튼은 무엇이 일어나는지 그대로 말해요. 버튼은 '입장하기', '다시 고르기'처럼 동사로 쓰고, 결과는 '2번을 골랐어요'처럼 사실로 써요.
- 이모지는 대본 속 메시지에만 써요. 인터페이스 문구에는 쓰지 않아요.
- 배드 엔딩은 벌이 아니라 웃음이에요. 빨간색이나 경고 표시 없이 결말 문장 하나와 '다시 고르기' 버튼만 둬요.

## 크기

- 무대 화면의 모든 값은 1920×1080 기준 px에 `--u`를 곱해요. 앱에서는 `--u: calc(min(100vw / 1920, 100vh / 1080))`예요.
- 대사 46, 선택지 42, 질문 54, 이름 38, 숫자 56~64, 보조 정보 32px예요.
- 위쪽 읽기 영역은 좌우 160px, 위 56px 여백 안에 둬요. 프로젝터 가장자리는 잘려요.
- 휴대폰 글자는 16px 이상, 질문 24px, 버튼 88px 높이, 입력칸 글자 18px예요.
- 한국어는 단어 중간에서 줄을 바꾸지 않아요(`word-break: keep-all`).

## 테마

`day`와 `night` 두 가지예요. 장면의 `night` 플래그(축제, 방, 새벽 PC, 에필로그)에 따라 판이 어두워져요. 어두운 강당에서 흰 판이 눈부시지 않게 하려는 거예요. 선택지 세 색은 두 테마에서 같아요.

## 일러스트

모든 그림은 ChatGPT 이미지 생성으로 같은 대화 안에서 만들어요. 기준 이미지 세 장(남주 캐릭터 시트, 캠퍼스 정문 배경, 타이틀 키 비주얼)으로 일관성을 지켜요. 프롬프트와 제작 목록은 [아트 디렉션](ART-DIRECTION.md)에 있어요.

## 하지 않는 것

- 여주 얼굴, 교복 (대학생이에요)
- 판 없이 그림 위에 바로 올린 글자, 그림 위 그라데이션 막
- 선택지마다 다른 색, 화면 아래쪽 대사창
- 보라색, 네온, 그라데이션 버튼, 두 번째 버튼 모양
- 형광펜 밑줄, 색 바꾼 강조 단어, 대문자 라벨
- 기울인 카드, 테이프, 종이 질감, 튀는 애니메이션, 한 글자씩 느리게 나오는 대사
